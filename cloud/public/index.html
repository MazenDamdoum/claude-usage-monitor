WidgetsHome Screen · Today · Lock Screen

Usage bars like this app: 5-hour in orange, the week in blue, with the quarters and caps.

The widget script is copied.

  1. Get Scriptable from the App Store (free).
  2. Open Scriptable, tap +, paste, then tap the title and name it Claude Usage.
  3. Home Screen or Today View: touch and hold, tap Edit → Add Widget, pick Scriptable and a size. Tap the new widget and choose Claude Usage as the Script.
  4. Lock Screen: touch and hold it, tap Customize → Lock Screen, tap the widget row and pick Scriptable. Add the rectangle (or the circle, or the one-line widget; each is added on its own). Tap the added widget and choose Claude Usage.
  5. Your widgets show every account together. To pin one widget to one account, set its Parameter to that name.
Unpair this iPhone?

It stops getting alerts and usage. To use it again you'll need a new link or pairing code.
